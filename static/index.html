Gmail OAuth2 Setup

Required for "Web application" OAuth Client:

In Google Cloud Console → Credentials, edit your OAuth 2.0 Client ID and add this exact URL under Authorized redirect URIs, then click Save:

http://localhost:8765/oauth2callback

How to get credentials.json (one-time setup):

  1. Open the Google Cloud Console — Gmail API and click Enable.
  2. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.
  3. Select Application type: Desktop app (or Web app with http://localhost redirect) and download the JSON file.
  4. Upload or paste the JSON below, or save it directly to /Users/avsprasad/Projects/team-emails/credentials.json.
